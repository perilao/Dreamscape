COMO JOGAR?

1. In Engine (Play)
- Abra o projeto na Unity 6000.6.0f1.
- Abra a cena principal do jogo (TeleportTestScene).
- Conecte o dispositivo VR.
- Em Build Profiles, verifique se a simulação XR está ativada (se estiver, desative).
- Clique no botão Play (▶) para iniciar o jogo diretamente no Editor.

2. Build and Run
- Com o projeto aberto, acesse File > Build Profiles.
- Selecione a plataforma de destino (Android).
- Clique em Build and Run.
- Escolha a pasta de destino, se solicitado, e aguarde a compilação e execução do jogo.

Observação: certifique-se de que o dispositivo VR, os drivers e as configurações de XR estejam corretamente configurados para a plataforma utilizada.
